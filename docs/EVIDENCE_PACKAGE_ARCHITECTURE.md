# Evidence Package Architecture

Week 8 evidence packages bind mapping candidates to source references and
snapshot locators.

Evidence packages record:

- package code and version;
- mapping candidate identity;
- field-level evidence items;
- freshness and review status;
- completeness;
- output level.

Current Week 8 packages are `internal_raw`, pending review, and not customer
eligible. Week 10 can cite them for internal decision candidates, but cannot use
them as approved customer-facing proof.
