# Agent Instructions

This repository is evidence-first. Do not add real cloud product facts unless
they can be traced to a `SourceDocument` and `Evidence` record.

Week 1 scope is limited to the database foundation:

- SQLAlchemy models and constraints.
- Alembic migrations.
- Pydantic data contracts.
- Lightweight repositories.
- Synthetic fixtures and tests.
- Data dictionary, governance, decisions, state, and handoff documents.

Do not implement web scraping, pricing API integration, vector search, RAG,
LLM calls, frontend UI, sales scripts, competitive scoring, automatic product
mapping, or real customer data ingestion during this phase.
